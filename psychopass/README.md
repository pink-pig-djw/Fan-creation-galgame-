# 四十九日

《PSYCHO-PASS 心理测量者》的**非官方同人视觉小说**。悬疑恐怖向。

> 死去的人，会在第四十九天回家。

- 时间：2114 年 12 月，第二季结束后一个多月。常守朱的祖母去世后的第四十二天到第四十九天。
- 主视角：常守朱（公安局刑事课一系　监视官）。
- 本作含有恐怖、死亡相关的描写（不含血腥画面）。设置里可以把「惊吓演出」调低或关掉。

## 怎么玩

用浏览器（推荐 Chrome / Edge）打开 `index.html`。如果浏览器拦截了本地文件，在这个文件夹里运行一个本地服务器，再访问 `http://localhost:8767`：

```bash
python tools/serve.py 8767
```

| 操作 | 按键 |

| 前进 | 鼠标左键 / 空格 / 回车 / 滚轮下滑 |

| 快速存档 / 读档 | S / L |

## 结构

```
序章「晚餐」→ 第一章「回家的人」→ 第二章「残像」→ 第三章「无色」→ 第四章「葬列」→ 第五章「第四十九日」→ 终章「哀悼」
```

- **体量**：剧本约 5.4 万字。正线（TRUE END）约 2.5 小时；四个 BAD END 各十分钟左右，全部看完约 3 小时。
- **结局 6 个**：TRUE END「四十九日」、NORMAL END「无色」、BAD END「里屋」「对象外」「浊色」「回家」。BAD END 很短，走进去以后可以用分支图回到之前的选项。
- **霜月美佳的色相**：和美佳有关的选项会让她的犯罪系数上升或下降，按 P 随时可以看。犯罪系数超过 100，就会被判定为潜在犯。
- **搜查档案**：剧中第一次出现的名词（西比拉系统、主宰者、色相……）会自动记进档案，没看过原作也能跟上。
- **分支图**：走过的场景会亮起，点一下就能回到那个时刻重新选择。

## 素材

- 图像全部由 Codex 图像生成（gpt-6-sol，medium）：角色立绘（含表情差分、全息影像）、背景、事件 CG、标题图。
- 背景音乐 15 首由 Suno 生成（纯音乐，`assets/bgm/`，prompt 见 `docs/suno_prompts.md`）。某首 mp3 读不到时，会自动换回 WebAudio 实时合成的版本。
- 音效和环境音由 WebAudio 实时合成。

## 目录

```
index.html            入口
css/style.css         界面样式
js/engine.js          引擎
js/audio.js           音乐 / 音效
js/assets.js          素材清单、搜查档案、结局
script/*.js           剧本
assets/bg|ch|cg|bgm   背景 / 立绘 / CG / 音乐
docs/设定集.md         人物与世界观设定（含剧透）
docs/大纲.md           分场大纲（含剧透）
docs/真相（剧透）.md     真凶与结局条件（剧透）
tools/                出图、校验、自动通关测试脚本
```

开发用的检查工具：

```bash
node tools/validate.js -ai   # 剧本静态检查 + 「AI 味」句式
node tools/paths.js          # 模拟全部分支，看每条路线落到哪个结局
node tools/headless.js       # 用无界面的 Edge 把全部结局真实跑一遍（需要先开 tools/serve.py 8767）
```
