# 《四十九日》幕后真相（剧透）

> 这一页写的是真凶、反转和结局条件。想先审核故事就看；想留着自己玩就别打开。

## 真凶：白鹭静司
- 「残像」的创始人。三年前在废弃区"死亡"：只找到他的血迹和外套，色相信号从此消失，西比拉把他登记为死者。公司之后由徒弟七濑雾接手，大厅里接待客人的"白鹭"是他的全息影像。
- 他其实还活着。他用的是第一季「头盔事件」那套技术的改进版：能让扫描器把自己读成另一个人。哀悼者交给「残像」的亡者生命日志和色相档案，就是他的衣柜。所以街头扫描器会拍到"已经死了的人在街上走"。
- 动机：妻子和女儿死于事故后，强制的色相护理把他的悲伤"治好"了，还劝他删掉她们的数据。他认定西比拉社会不允许人哀悼，放不下的人其实已经和死者一起死了。
- 手法：第四十九天，他披着死者的色相登门，门口的扫描器显示"家人回家了"。全息影像劝说，他递上一杯高剂量的色相护理镇静剂，让他们"一起走"。雏河凭药物鉴定找出这一点。
- 为什么盯上朱：祖母死后，朱的色相依旧清澈。他想知道这个人是怪物，还是他的同类。
- 为什么盯上美佳：美佳有一句话一直没对川原崎加贺美说出口。他用加贺美的影像把美佳引到樱霜学园旧校舍，逼朱在"祖母的四十九日"和"恨她的人"之间二选一。

## 高潮
- 樱霜学园旧礼拜堂。他披着加贺美的色相出现，主宰者读出「川原崎加贺美（记录：已死亡）」，犯罪系数 18——那是加贺美两年前存档里冻结的数值，一下都不跳。
- 朱拆掉伪装装置。主宰者重新读取：「白鹭静司／已死亡／犯罪系数 0」。免罪体质，主宰者锁死。
- 朱给他戴上手铐："那就由法律来判断。"
- 禾生局长亲自来接人，无人机换下了朱的手铐（手铐掉在长椅底下，后来美佳把它送到了老房子的缘侧）。记录上，白鹭"在押送途中死亡"。房间里只有朱和美佳知道西比拉要他做什么，两人都没有说出口：这成了只属于她们的秘密。
- 终章（TRUE）最后一句惊吓：禾生用白鹭的口头禅说了一句话。
- 白鹭在供述里交代：第一条留言知道「站着吃饭团」，是因为生前预约会同步收件人家里 AI 的生活日志；佛坛的照片是他扣下的（影像不该看见自己的遗照）；三枝家的门禁是他在街口遥控的；河边的外套和血是他自己留的。

## 祖母的留言（TRUE / NORMAL 的分界）
- 两年前，常守葵自己报名了「残像」的「生前预约」，录了几段给朱的话，约定在她的四十九日送达。
- 白鹭劫持了这个账号来接近朱，内容被他篡改过。七濑雾在离线存档里保留了原始录音。
- 第二章选择删除祖母的账号 → 离线存档一起被清空 → NORMAL END「无色」：案子破了，但朱没听到祖母真正的话，也还是没哭。美佳调休不来，两人什么都没解开。深夜 Candy 推送「残像」三十天后恢复营业、要不要为常守葵预约，朱随口一句「就这样吧」被当成了同意——祖母的影像会在一月二十日「回家」。（NORMAL 没有局长那一场，惊吓换成这一个。）
- 保留账号，第四章又没有指控七濑雾 → TRUE END「四十九日」：雾把原始录音交给朱。朱终于哭了出来，色相依旧清澈。美佳在门外听着。

## 美佳这条线
- 第二季里，美佳曾按东金的要求查出常守葵的下落。她一直背着这件事；朱知道，却从来没提过。
- 耳光的真正原因："是我把你奶奶的位置交出去的——你为什么连恨都不恨我？！"
- 结尾两人不会变成朋友：美佳不道歉，朱说"我知道"。
